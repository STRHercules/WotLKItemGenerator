ENVIRONMENT-DEPENDENT VERIFICATION STILL REQUIRED
-------------------------------------------------
This Linux sandbox has no Rust/Cargo toolchain, no PowerShell/Windows environment,
and cannot resolve npm's registry. Therefore this snapshot does NOT claim that the
final Windows installer has been compiled or smoke-tested here.

On a Windows build machine with Python, Node/npm, and Rust installed, run:

    .\scripts\build-windows-release.ps1

That script performs the full release verification, builds the Nuitka engine,
stages the Tauri sidecar, builds the NSIS installer, and writes release evidence.

The GitHub Actions workflow at .github/workflows/windows-build.yml invokes the
same canonical script and uploads the installer plus release manifest artifacts.
